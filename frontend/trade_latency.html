How Trade Latency Is Calculated

Order Sent

Message type 35=D (New Order Single)

Timestamp: Tag 52 SendingTime

Keyed by: Tag 11 ClOrdID

Fill Received

Message type 35=8 (Execution Report)

ExecType 150=1 (Partial Fill) or 150=2 (Fill)

OrdStatus 39=1 or 39=2

Trade Latency (ms) = Fill SendingTime (tag 52) − Order SendingTime (tag 52)  ·  Matched via ClOrdID (tag 11)
